## 1. 背景与目标

### 1.1 问题陈述
当前微信小程序存在以下问题：
- **视觉方面**：整体配色和风格不吸引人、界面布局混乱、组件设计粗糙
- **体验方面**：操作流程不清晰、核心功能难用、性能问题、错误提示不友好

### 1.2 设计目标
- 采用活泼有趣的视觉风格，降低学生学习压力
- 优化操作流程，使核心功能更加易用
- 提升性能，改善加载速度和响应性
- 提供友好的错误提示和引导

---

## 2. 设计方案：彩虹世界

### 2.1 设计风格定位
**活泼有趣风格** - 色彩丰富、圆润友好、轻松活泼

### 2.2 配色方案

每个页面拥有独特的主题色渐变：

| 页面 | 主色调渐变 | 色值 |
|------|-----------|------|
| 作业列表页 | 紫色系 | `#667eea` → `#764ba2` |
| 提交作业页 | 粉红系 | `#f093fb` → `#f5576c` |
| 批改结果页 | 蓝色系 | `#4facfe` → `#00f2fe` |
| 个人中心页 | 绿色系 | `#43e97b` → `#38f9d7` |
| 消息通知页 | 橙粉系 | `#fa709a` → `#fee140` |
| 学习报告页 | 青粉系 | `#a8edea` → `#fed6e3` |

**通用配色**：
- 主文字：`#333333`
- 次要文字：`#666666`
- 提示文字：`#999999`
- 背景色：`#f5f5f5`
- 卡片背景：`#ffffff`

### 2.3 设计语言

**组件特点**：
- 大圆角（16px-24px）
- 胶囊形状按钮（border-radius: 100px）
- 渐变色作为强调
- 图标化导航
- 微动效反馈

## 3. 页面设计

### 3.1 作业列表页（首页）

**布局结构**：
1. 顶部欢迎区 - 紫色渐变背景，显示问候语和待完成作业数
2. 筛选区 - 胶囊形状标签（全部/进行中/待补交）
3. 作业卡片列表 - 每个卡片包含标题、截止时间、状态标签、操作按钮

**交互**：
- 下拉刷新
- 筛选切换动画
- 卡片点击进入作业详情

### 3.2 提交作业页

**布局结构**：
1. 作业信息卡片 - 显示作业标题和要求
2. 图片上传区 - 虚线边框，拖放式设计
3. 已上传图片预览 - 可删除预览
4. 批改模式选择 - 标准批改/快速批改，卡片式单选
5. 提交按钮 - 大号渐变按钮，固定底部

**交互**：
- 图片压缩后上传
- 支持拍照和相册选择
- 自动保存草稿

### 3.3 批改结果页

**布局结构**：
1. 分数展示区 - 蓝色渐变背景，大号分数显示，维度得分标签
2. 改进建议卡片 - 列表形式展示建议
3. 错误分析 - 原文与修改对照显示

**交互**：
- 自动轮询状态
- 分数动画效果
- 错误高亮显示

### 3.4 个人中心页

**布局结构**：
1. 用户信息卡片 - 头像、昵称、班级
2. 功能菜单列表 - 修改资料、修改密码、API设置、草稿清理
3. 退出登录按钮

### 3.5 消息通知页

**布局结构**：
1. 消息列表 - 按时间倒序排列
2. 消息类型图标 - 公告/批改完成/新作业等
3. 已读/未读状态区分

## 5. 交互优化

### 5.1 提交流程优化

1. **查看作业** → 2. **上传照片** → 3. **选择模式** → 4. **提交成功**

每一步都有明确的视觉反馈和引导。

### 5.2 错误提示优化

| 错误类型 | 视觉处理 | 提示文案 |
|---------|---------|---------|
| 上传失败 | 淡红色背景 + 表情图标 | "图片太大啦，请压缩后再试试～" |
| 网络慢 | 淡黄色背景 + 表情图标 | "网络似乎有点慢，正在努力连接中..." |
| 提交成功 | 淡蓝色背景 + 表情图标 | "提交成功！批改大约需要1-2分钟" |

### 5.3 性能优化措施

| 优化项 | 实现方式 |
|-------|---------|
| 图片压缩 | 上传前自动压缩到合适尺寸 |
| 智能缓存 | 常用数据本地缓存，减少网络请求 |
| 骨架屏 | 加载时显示骨架屏而非空白页 |
| 懒加载 | 列表滚动时按需加载内容 |

## 7. 技术实现要点

### 7.1 样式架构

```css
/* 全局 CSS 变量 */
page {
  --primary-gradient: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
  --border-radius-large: 16px;
  --border-radius-pill: 100px;
  --shadow-soft: 0 2px 12px rgba(0,0,0,0.06);
}
```

### 7.2 组件复用

创建通用组件库：
- `gradient-button` - 渐变按钮
- `status-tag` - 状态标签
- `card` - 卡片容器
- `upload-area` - 上传区域
- `loading` - 加载状态

### 7.3 状态管理

使用 MobX 或简化版状态管理，统一管理：
- 用户信息
- 作业列表
- 提交状态
- 草稿数据

## 8. 验收标准

### 8.1 视觉验收
- [ ] 所有页面使用正确的主题色渐变
- [ ] 组件圆角统一为 16px 或胶囊形
- [ ] 按钮使用渐变背景且有一致的视觉风格
- [ ] 图标使用统一的设计语言

### 8.2 交互验收
- [ ] 提交流程顺畅，每步有明确反馈
- [ ] 错误提示友好，包含表情和解决建议
- [ ] 加载状态统一，使用骨架屏
- [ ] 底部导航切换流畅

### 8.3 性能验收
- [ ] 图片上传前自动压缩
- [ ] 首屏加载时间 < 2秒
- [ ] 列表滚动流畅无卡顿
